# 數學素養判讀

會考數學（111–115 年）、學測數學（107–115 年，含數A、數B）與分科數學（107–115 年指考與分科測驗數甲、數乙）共 636 題的數學素養分析。每一題都標上四項：

- **歷程**（PISA 數學素養）：形成（F）、運用（E）、詮釋與評估（I）、數學推理（R）
- **解題策略**：畫圖作圖、列式建模、代入與特例、分類討論、逆推與反面思考、找規律、轉換表徵、直接運算、估算與排除
- **常見錯誤**：條件遺漏、概念混淆、計算失誤、圖表誤讀、題意轉譯錯誤、情況討論不全、直覺陷阱
- **判讀提示**：一句解題方向

本專案由 [huikao-analysis](https://github.com/bgjd315-cloud/huikao-analysis) 的數學部分複製而來，與國文版、英文版是各自獨立的網站。

## 頁面

| 路徑 | 內容 |
|---|---|
| `/` | 數學素養總覽：重點發現、歷程分布、各歷程答題方法、解題策略、常見錯誤、會考到學測與分科的銜接 |
| `/bank/` | 判讀題庫：依考試、年度、歷程、策略、錯誤篩選，可遮住答案與提示自我練習 |
| `/practice/` | 數學練習卷：依歷程、策略或錯誤隨機抽 10 題（單選、多選），作答後看提示，最後顯示各歷程答對率；累計紀錄只存在使用者瀏覽器 |
| `/math/` | 會考數學命題分析與原題試題庫 |
| `/xuece-math/` | 學測、分科數學命題分析與原題試題庫 |

## 資料

- `tools/reading_cls.py`：逐題判讀，依測驗（math、m、ma、mb、mj、mi）與年度分段，每題一筆「歷程 策略 錯誤 提示」，以「｜」分隔，順序與試卷相同
- `tools/reading_data.py`：把判讀與 `data/` 的題目、答案合併，供頁面與練習卷使用
- `tools/dump_stems.py`：把題目整理成純文字（`work/stems.txt`），逐題判讀時參考
- `data/math/`、`data/xuece-math/`：各年度題目、答案與分類
- `assets/`：從官方試卷裁切的題目圖片

## 建置與檢查

```bash
python build.py
python tools/verify.py
```

`build.py` 會檢查每份試卷的題數與判讀數是否一致；推送到 main 後由 GitHub Actions 自動發布到 GitHub Pages。

## 新增一年

1. 依 huikao-analysis 的 `docs/年度更新流程.md` 產生該年度的 `data/<math|xuece-math>/<年度>.json` 與題目圖片，複製到本專案
2. 執行 `python tools/dump_stems.py`，在 `tools/reading_cls.py` 補上該年度各測驗的逐題判讀
3. 執行 `python build.py` 與 `python tools/verify.py`
